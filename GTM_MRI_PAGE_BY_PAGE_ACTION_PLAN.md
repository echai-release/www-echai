# GTM MRI Page-by-Page Action Plan

This plan maps the remaining MRI gaps to specific pages in the site.

Assumptions for this version:
- Completed by user: LoopX is now the primary wedge, and the broader multi-product positioning issue has already been addressed.
- LoopX is no longer in pilot.

Priority key:
- P0 = highest impact / do first
- P1 = important follow-up
- P2 = useful cleanup / supporting work
- P3 = optional for current MRI scope

## Existing Pages

### `index.html` - Homepage
Priority: P0

Goals:
- Tighten ICP clarity on the homepage
- Improve proof and conversion confidence
- Make next steps easier for buyers to understand

Action items:
- Add a clear "Who LoopX is for" section with:
  - primary buyer roles
  - company stage / size guidance
  - sales motion fit
  - CRM / workflow fit
- Add a short "Not for" block to sharpen qualification.
- Add stronger proof near the hero or below the hero:
  - named customer logos if approved
  - anonymized proof with firmographic context if logos are not ready
  - 1-2 short measurable outcomes tied to buyer type
- Add a "What happens after you request a demo / start a trial" section.
- Keep one primary CTA and one secondary CTA per section.
- Add direct links to the future `pricing.html`, `proof.html`, `integrations.html`, and `implementation.html` pages.

- ICP visibility
- outcome proof
- CTA clarity
- follow-up path
